# Japanese Reference Pack — Draft Scaffold

This folder is intentionally **not a complete Japanese curriculum yet**. It is a schema/conformance seed and a roadmap target.

OMP must build the real pack through the research/validation tasks in `tasks/ROADMAP.yaml`. Do not promote this pack beyond `experimental` until review requirements are met.

The sample unit exists to exercise the format. Treat linguistic examples as content requiring normal review before stable release.

Draft speech features are guided/reference only. The null confidence threshold and false assessment capability flags deliberately disable automatic grading; no provider, model, human-reviewed targets or calibration evidence has been selected. Requested model capabilities are research targets, not availability promises.

The goal's missing transfer assessment is declared in `manifest.yaml` as an exact unresolved reference. Handoff validation may report it as an experimental warning; release-readiness must fail until a real reviewed definition exists. The original-content license, full inventories/graphs, actual lesson/reference audio, lexical sourcing, and qualified human content review also remain unfinished. Empty accepted-variant data cannot authorize rejection of natural variants.
