# UI/visual review — LTS vs the 2026 language-app market

Date: 2026-11-23. This doc re-verifies the visual audit against the live app (serve mode, `http://127.0.0.1:17631/`) and marks what has moved since. The ranked backlog lives in the kanban board (`tasks/KANBAN.md`, heading `## UI backlog — 2026-11-23`).

Evidence: live DOM reads of Today/Practice/My Words/Progress/profile-chooser (2026-11-23) + the built CSS token sheet + prior in-app audits. **Caveat**: no pixel inspection (no vision in this session); claims about contrast/spacing/pixel-level defects are limited to DOM/CSS-level observations. Pixel-level re-verification requires a tight-crop human pass.

## What the shipped product already does well (vs Duolingo/Busuu/Anki/Quizlet/LingQ)

- Calm single-accent palette (cream `#f5f1e9` + teal `#14615e`, single accent, serif display type) — one accent = interactive/selected state, matching the cross-cutting "strict accent semantics" pattern the market converged on. Not a dark pattern anywhere; no streaks, no hearts, no leagues — matches the owner's explicit G5 rejection and Russio's "no streaks, no guilt".
- Hub + single-task-flow shape (Today = greeting → plan budget picker → Start CTA → collapsed queue) matches the hub pattern (Duolingo/Anki/Babbel).
- In-session chrome shipped: `.session-chrome` / `.session-bar` / `.session-chrome-meta` — thin progress bar + "n of M · ~M min" + pause/resume summaries.
- Progress screen shipped per PROGRESS-STATS-001: per-goal modality bars (dim-progress SVG), memory stats strip (due today, ~minutes, retention by band, 12-week calendar), readable labels (no raw `ja:lex.*` tokens in the rendered output — audit finding closed).
- Practice hub is now self-describing: each mode card carries a grade-state badge (`.mode-grade-badge`, `--graded` for graded vs formative) — the "is this scored?" honesty promise is visible, not prose-only.
- Word-tap reader + word-card bottom-sheet (READER-FLOW-001): printed form + stress + lemma + gloss + grammar line + PLAY from sliced word timings; aux-lexicon overlay; never leaves context.
- Graded vs formative is visible everywhere and gates mastery (never counted) — the core honesty value, now operationalized.

## Where we still trail the market

1. **Copy density** — Goal titles are full requirement sentences ("Recognize and copy every printed Cyrillic letter, one sound per letter, and interpret the teaching stress mark."). Duolingo/Babbel/Quizlet use short task-card phrasing. This is the largest remaining copy-hygiene gap. (UI-HYGIENE-001, still open)
2. **Reading word-state coloring** — LingQ/LangLeap/NuanceDeck mark unseen/learning/confirmed inside the text. READER-FLOW-001 shipped the card/tap layer; the in-text state coloring is unconfirmed/not shipped.
3. **Karaoke / word-synced highlight** — parked deliberately (STORY-LISTEN-001 parked by owner 2026-11-18). Correct call, but it leaves us behind Beelinguapp/LingQ in the "audio welded to text" pattern.
4. **SRS transparency on grade buttons** — `.grade-preview` exists; needs a human pass to confirm the next-interval text actually renders on every grade action.
5. **Designed empty states + light illustration layer** — empty states are honest-but-bare ("Nothing mined yet"). No line-art or warm glyphs (audit U10).
6. **Profile chooser** — one real profile on this instance renders clean (avatar letter + aligned card + pack + due state). The audit-era fixture-clutter issue is environment-specific; U13 (archive/hide fixtures, dedupe) still worth a targeted pass on the owner's machine.
7. **In-session completion state** — Duolingo/Quizlet end a session with a celebratory terminal state. GUIDED-SESSION has pause/resume/finish but no 0.4-era celebratory summary; low priority.
8. **Correction-in-artifact** — dictation/speech feedback marks the wrong form near the sentence, not inside it in the transcript (Praktika pattern, audit U9). ERR-SRS-LOOP-001 shipped the offer surface but not the in-artifact highlight.
9. **Scenario scene view** — LangLeap-style tappable characters: deferred intentionally; don't chase before G1.

## Verdict

**Visually we're at "respectable, honest, clearly productized" — a real, consistent design system, not a rough prototype.** We are BEHIND on density phrasing, word-state coloring, and empty-state illustration; at parity on session chrome, grade-transparency, progress instruments, and the word-card reading layer; AHEAD on honesty (no dark patterns, no manufactured urgency) and on per-goal modality progress visualization. We are NOT a visual clone of Duolingo — we shouldn't be — and the biggest single upgrade is typography/density restraint, not more color.

## Recommendation order (ranked by effort × visible impact)

1. Copy-hygiene pass (short goal/unit titles) — small, high visible impact
2. Human pass on grade-preview + session-chrome rendering (evidence only)
3. Word-state coloring in the reader (pairs with READABILITY-GATE-001)
4. Designed empty states (light illustration or at least copy + glyph)
5. Correction-in-artifact for dictation/speech feedback
6. Accumulation meters in the Today header strip (My Words count, worlds unlocked)
7. Designed scenario scene view — only after G1 (guided conversation) exists
