# K-20 — Agent-facing pack authoring contract (PACK-AI-001 subset)

## What shipped

One contract document an agent can follow end-to-end, plus the
templates it references — all machine-checked so the docs cannot drift.

## Deliverables

- `docs/PACK_AUTHORING_CONTRACT.md` — the single contract: hard rules
  (data-only packs, provenance, honest review status, ID grammar),
  the full 0.2 layout table (verified against `layout.rs`, including
  the `lexicon/*.jsonl` line that was missing from its doc comment —
  fixed there too), the gate ladder (`validate` → `lint` → audits →
  `test` → `build`), the per-unit workflow, and pointers to the
  templates.
- `tools/pack-templates/unit-brief.md` — per-unit authoring brief:
  identity, exactly which ids the lesson introduces, sources,
  validation method, activity plan table, post-write gates.
- `tools/pack-templates/example-pack/` — worked complete unit in a
  minimal lint-clean pack (manifest, goal + assessment, concept,
  3 lexicon entries, sentence with cloze target, unit with
  encounter/recall/cloze/dictation). Placeholder `xx` locale, CC0
  self-authored content.
- `tools/pack-templates/ci-community-pack.yml` — GitHub Actions
  template: `langpack test` on every push/PR, `.lpk` artifact on tags.
- `docs/QUICKSTART_PACK_AUTHORING.md` cross-links the contract.

## Tests

- cli `worked_example_template_pack_stays_clean`: the example pack
  must pass `validate`, `lint`, and `audit-curriculum` — agents can
  copy it with confidence; doc drift fails CI.
