# K-46 — runtime device-tier detection → dynamic recommended speech model (2026-10-07)

## What shipped

The "recommended" badge on the speech-model picker is no longer a
static constant (`RECOMMENDED_SPEECH_MODEL` deleted). It now comes from
measuring this device at runtime.

- Native (`apps/desktop/src-tauri/src/lib.rs`):
  - `recommended_speech_model()` command → `DeviceTier { cores,
    total_ram_mb, tier, recommended_model }`.
  - `measure_device()`: logical cores via
    `std::thread::available_parallelism()`; total RAM from
    `/proc/meminfo` `MemTotal` (Linux). Unreadable → 0, which means
    detection failed.
  - `classify_device_tier(cores, ram_mb)` (pure, testable): tier
    thresholds follow the PERF-001 tier shape in
    `docs/performance/BUDGETS.yaml` (low 4c/8GB, typical 8c/16GB, high
    16c+/32GB+). Recommendation follows the memory budgets
    (`total_with_compact_model_mb`: low 2000, typical 1500): low →
    tiny, typical → base, high → small. Detection failure →
    `recommended_model: None` (honest abstention, never a guess).
- UI (`language.tsx`): `DeviceTier` type + `deviceTier` prop; badge
  renders "recommended for this device" only on the detected model;
  copy states the detected tier and numbers ("This device was detected
  as the typical tier (8 cores, 16000 MB RAM).") or, on failure, "could
  not be detected, so no model is recommended — pick one your device
  can comfortably run."
- `App.tsx`: `deviceTier` state fetched via `recommended_speech_model`
  in `refreshSpeech`.

## Honesty invariants

- No static recommendation: the badge moves with the measured device.
- Detection failure abstains (null) and the UI says so.
- Existing honest framing kept: model sizes give the same result for
  pronunciation feedback (ADR-0011); tier copy explains the choice is
  about device comfort, not accuracy.

## Tests

- Native `device_tier_detection_recommends_by_measured_capacity`:
  low/typical/high classifications, RAM-poor-but-many-cores stays low,

  >0 RAM (Linux path).
- UI `language.test.tsx` speech-model test updated: badge lands on the
  detected model exactly once, tier copy renders with the injected
  tier's numbers.
