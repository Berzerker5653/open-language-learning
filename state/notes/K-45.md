# K-45 — ja-JP kanji layer expansion + A2 content

Date: 2026-10-07. Five slices, all shipped.

## Slice 1: sharded pack directories reach every reader

K-45's content expansion (kanji shards, A2 sentences/contrasts)
relies on the chunking conventions (`kanji/n5.jsonl`,
`sentences/food.jsonl`, …). The engine's lexicon reader already
honored them (K-22 era fix); kanji, sentences, and phonology readers
were still hardcoded to single files — expansion would have been
invisible to drills, the cloze/dictation runner, the discrimination
runner, and the claims panel.

- `jsonl_dir_texts(data, pack_id, version, dir)`: every `*.jsonl`
  under an installed pack directory, file-name order (generalizes
  `lexicon_texts`).
- `kanji_entries`, `sentence_entries`, `contrast_entries` now read
  all shards (empty-list semantics for absent dirs preserved for
  kanji/contrasts; sentences keeps the error).
- `jsonl_dir_claims(root, dir)` + claims panel: sentences, kanji,
  phonology tallies now sum every shard file.
- `dictation_target_at` (slice 4 follow-up) reads every
  `sentences/*.jsonl` too — shard sentences reach the dictation
  picker.

## Slice 2: greeting set phrases annotated (K-44 follow-on)

`lexicon/greetings.jsonl`: five set phrases (おはようございます,
ありがとうございます, おめでとうございます, おやすみなさい,
またあした) declare `kind: "phrase"` + verbatim slots (time-of-day /
polite-ending / when-next structure).

## Slice 3: kanji layer expansion

`kanji/a2-topics.jsonl`: 28 new draft records covering the A2 goal
topics — weather (天 気 風 雲 雨 雪 晴), place/nature (森 花 町 家 者),
body/health (心 体 頭 眼), daily-admin (期 会 変), entertainment
(映 絵), sports (強 射), relationships (友 愛 話), city services
(届 使). All draft-labeled, ai-assisted generation provenance,
jmdict-simplified as the pending verification source. Kanji drill
resurfaces characters via SRS; furigana/reading gating rides the
existing reader (READ-001) — no engine change needed because slice 1
made shards visible.

## Slice 4: A2 sentence content

`sentences/a2-daily.jsonl`: 19 draft sentences across the ten A2
goal topics, with reading/romaji/gloss and cloze targets verbatim in
the text (validator enforces `cloze_target_not_in_text`). Also
removed the duplicate 七 kanji record (`ja.kanji.shichi` shadowed
`ja.kanji.nana`, which units reference).

## Slice 5: verb set phrases annotated

`lexicon/verbs.jsonl`: ten productive patterns — stem+ます (たべます,
のみます, よみます, かきます, いきます, きます) and noun+します
(かいものします, べんきょうします, あいさつします, しょうかいします)
— with verbatim slots so the runner shows the decomposition learners
need at A1/A2.
