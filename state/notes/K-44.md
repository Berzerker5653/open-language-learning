# K-44 — first-class `phrase` lexicon entries with slot info

Date: 2026-10-07.

## What shipped

- **Pack format**: `schemas/v0.2/lexicon-entry.schema.json` gained
  optional `kind` (`"word"` | `"phrase"`, default word — existing packs
  unaffected) and `slots` (array of `{text, alternatives?, label?}`).
  Additive optional fields in 0.2; no schema-version bump needed.
  Convention documented in `docs/PACK_AUTHORING_CONTRACT.md`.
- **Native parsing** (`apps/desktop/src-tauri/src/lib.rs`): `LexEntry`
  carries `kind` + `slots: Vec<PhraseSlot>`. Verbatim rule: a slot's
  `text` must occur in the primary surface form or it is dropped —
  never guessed (same discipline as sentence `cloze_targets`). The
  engine never parses the language; slots are pack-declared.
- **Runner**: `PracticeTask.slots: Vec<PhraseSlotView>` adds
  `target: bool` — exactly one deterministic target per item via
  `fnv1a(item_id) % slots.len()` (same FNV rule as choice placement,
  no RNG). Only the lexicon builder populates slots; the other five
  task builders pass empty.
- **UI** (`apps/desktop/src/practice.tsx`): the runner renders a
  "Phrase structure" block under the surface — target slot badged
  "the part to change", optional label, alternatives listed.
  Display-only: grading/evidence/scheduling never consult slots
  (grading path untouched by construction).
- **Schema validation**: `cargo test -p lts-langpack --test validate`
  (32 tests) passes with the extended schema; installed packs with
  `kind`/`slots` validate.

## Tests
