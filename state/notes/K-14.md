# K-14 — Sentence mining / learner-owned lexicon

## What shipped

Words the learner chooses to keep, with a citation of where they were
met — a language-agnostic engine feature (not pack data), device-local.
Mined items get their own SRS scheduling and NEVER write mastery
evidence or touch pack-content scheduler rows.

## Persistence (migration v4)

- `crates/storage`: `SCHEMA_VERSION` 3→4; new `mined_items` table
  (id, profile_id FK, surface UNIQUE per profile, reading, gloss,
  source_citation, created_at). Forward-only migration per docs/08.
- New `mined.rs` module: `add_mined` / `mined_items` / `remove_mined`
  (delete also drops the item's `scheduler_state` row — a deleted word
  must not keep resurfacing).
- docs/08 table list updated.

## Engine (`apps/desktop/src-tauri/src/lib.rs`)

- Commands: `mine_add` (surface ≤100 chars, citation required),
  `mine_list` (joins due dates from scheduler rows), `mine_remove`
  (id must start `mine-`), `mine_due`, `mine_grade` (self-graded
  recall: Again/Good → FSRS spike row keyed `mine-<ts>-<ns>`,
  SPIKE_VERSION scheduler).
- Isolation invariant: mined ids are not content ids; they can never
  enter evidence_events (ContentId-typed) and their scheduler rows are
  namespaced `mine-*`, separate from `<content>#<dimension>` rows.

## UI (`apps/desktop/src/App.tsx`)

- "My Words" route: due-review card (surface → Reveal → gloss +
  citation → I knew it / Again), add form (surface/reading/gloss/
  citation), list with due dates + Remove.
- Story reader lookup entries gained a "Mine" button that cites the
  story content id automatically.

## Tests

- storage `mined_items_crud_and_cascade`: add/list/remove, citation
  preserved, SRS row dropped on delete; migration test now expects
  versions [1,2,3,4].
- desktop `mined_words_schedule_without_touching_mastery_evidence`:
  add → grade → due date present; evidence table EMPTY; the only
  scheduler row is `mine-*`.
