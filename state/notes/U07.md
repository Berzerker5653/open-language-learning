# U07 — scenario support promised help and delivered none (owner review 2026-10-14)

**Change (runtime, commit 8dc4000, authored on Omarchy, applied + verified on GamingPC):** 0.2 scenario nodes now carry `action_labels` (learner-facing wording per intent token) and per-node `support` payloads (`level`, `kind ∈ hint|model|gloss|choices`, `text`, optional `options`) covering every ladder rung above 0. The pack validator enforces the promise — `scenario_support_rung_undelivered`, `scenario_action_label_missing` (node AND recovery-branch tokens), `scenario_support_choices_small` — all Severity::Error, v2 docs only, with three langpack tests pinning the codes. On the wire, actions are `{intent,label}` and the raw token is never a label (fallback "Respond"); `support_at` answers with `delivered_help` for the rung just used, and `scenario.tsx` renders it (model text, gloss, choices list). docs/04 documents the fields and codes.

Every file carries the ai-drafted REVIEW-001 notice — **content review by a qualified human is still open; this wave does not claim it**.
