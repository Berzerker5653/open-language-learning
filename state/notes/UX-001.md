# UX-001 — Onboarding and privacy-first Japanese selection

Date: 2026-10-03

## Acceptance mapping

1. **No account required.**
   - Profile is created locally via `create_profile` (SQLite `profiles.db` under
     `$XDG_DATA_HOME/openlang`); no email/password fields exist anywhere in the flow.
   - UI test `onboarding.test.tsx` asserts welcome/done steps contain "No account
     required" and no `type="password"` / "email" / "sign up" / "log in".
   - Rust test `bundled_japanese_pack_installs_and_records` proves a usable profile
     exists with zero network/account steps.

2. **Japanese pack can be selected/installed.**
   - `available_packs()` lists the bundled candidate `org.openlanguage.ja-demo`
     (ja-JP); `install_pack(pack_id)` validates + installs it (allowlisted ids only,
     UI never supplies paths — docs/07 privilege boundary).
   - Rust test installs the Japanese pack end-to-end (scaffold validation,
     install-mode license gates, `record_installation` trust "community") and
     rejects unknown ids.
   - UI test asserts the packs step renders the Japanese candidate with Install
     and gates Continue until selected+installed.
   - Pack content is EDRDG/JMdict-derived under CC BY-SA 4.0 (source license
     governs; no project-original content needing LIC-001). The unlicensed
     `ja-curriculum-draft` pack is deliberately NOT installable — install-mode
     validation rejects it (honest LIC-001 blocker, not self-certified).

3. **Microphone setup is skippable.**
   - Microphone step offers "Enable microphone" and "Skip for now"; both call
     `complete_onboarding(profile_id, pack_id, mic_enabled)`.
   - Skipping persists setting `microphone-enabled = false` (Rust test round-trip)
     and never blocks reaching the app home.

4. **Local-processing/privacy behavior is explained.**
   - `privacy_notice()` returns the behavior the app actually implements today
     (docs/08): local-first, no account, recordings local + permission-gated,
     uploads only via explicitly enabled providers with a notice. Rendered on the
     welcome step before any data-producing action.
