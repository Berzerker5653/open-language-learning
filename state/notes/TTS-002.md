# TTS-002 notes — TTS distribution variants (ADR-0009)

Implemented 2026-10-04 per owner decision recorded in ADR-0009.

## What changed
- `models.rs`: `ModelFile.dir` directory entries — zip archive pinned by
  one sha256 (multi-file pin), safe extraction (no traversal/symlinks,
  10x size cap, unix modes preserved), per-member hash manifest in
  `installed.json`, corruption-aware `verify_installed`.
- `models/catalog.json`: `org.openlanguage.speech.kokoro-multi-lang`
  (first directory entry) + `org.openlanguage.speech.sherpa-onnx-runtime`
  (linux-x64). URLs PENDING-RELEASE-URL until O-05.
- `lib.rs`: `resolve_tts` layered resolution (bundled > model > env
  `LTS_TTS_DIR` > bench); `BUNDLED_TTS` set from `resource_dir()/tts` at
  setup; `tts_status` command with attribution + payload model state.
- `scripts/build-tts-variants.sh`: stages the TTS-bundled payload +
  license texts + `NOTICE.md` source offer; emits the tauri config
  overlay. Bare variant = default config (no payload).
- `third-party/notices/`: GPL-3.0, Apache-2.0, ONNX MIT texts + NOTICE.md
  (payload-scoped obligations, espeak-ng source offer).
- Languages panel: "Speech & attribution" section (status, component
  licenses, Download/Remove for payload models).
- docs/13: build mechanics + `LTS_TTS_DIR` layout + honest degradation.

## Decisions
- Archive-hash pinning (not per-file catalog entries): espeak-ng-data is
  ~392 files; one archive hash pins the tree, per-member hashes are
  recorded at install for corruption detection.
- Runtime + model as two separate directory entries so the bare variant
  can install the whole payload in-app; `TTS_PAYLOAD` ids centralized as
  consts in lib.rs.
- Overlay uses absolute resource path (script-local artifact; avoids
  tauri overlay path-resolution ambiguity).

## Limits / follow-ups
- Release *bundles* (appimage/deb assets per variant) are REL-001/O-04
  work; this task proves staging + config merge + binary build.
- Download URLs pending O-05; in-app Download button honestly surfaces
  the download error until then.
- Runtime entry is linux-x64 only (matches current vendor); other
  platforms need per-platform entries later.
