# UI-DESIGN-2026-10-03 — design system + full-app styling pass

Owner-directed task: the interface had no stylesheet at all; turn it into a
cohesive, calm, warm editorial learning workspace without changing behavior.

## What changed

- New `packages/ui/src/styles.css`: tokens (warm paper neutrals, single deep
  teal accent `#14615e`, semantic ok/warn/err reserved for feedback),
  system font stacks incl. Japanese fallbacks (serif display headings),
  shared components: buttons (primary/quiet), segmented budget control,
  stepper, cards, badges (text-labeled, never color-only), plan/place/pack
  lists, table wrapper, notice/alert/empty states, verdict states with
  glyph+text, focus-visible rings, responsive breakpoints, reduced-motion.
- `@openlang/ui` exports `./styles.css`; imported once in `main.tsx`.
- `AppShell`: optional `routeNav` slot in the banner; pinned landmark
  markup preserved exactly (tests).
- `App.tsx`: route switcher moved from bottom-of-main into the header with
  `aria-current="page"` active state.
- Views (`home`, `onboarding`, `pronunciation`, `writing`, `language`):
  classes + minor hierarchy changes (badges for open/locked/active,
  structured plan rows, feedback cards, pitch contour strokes themed via
  CSS). All test-pinned strings/attrs preserved.

## Verification (2026-10-03)

- `pnpm -r typecheck`, `pnpm lint`, `pnpm fmt:check`: clean.
- `pnpm -r test`: 26 tests pass (21 desktop + 3 ui + 2 shared).
- `vite build`: CSS bundles (9.86 kB).
- Real Chromium (headless) against a throwaway Tauri-IPC mock page
  (exact backend response shapes), desktop 1280px + mobile 390px:
  full journey welcome → profile → pack install → mic skip → home →
  progress → pronunciation → languages walked; computed styles confirm
  tokens applied; 0 horizontal overflow at both widths; table scrolls
  inside its wrapper on mobile; long content ids wrap; keyboard Tab
  shows 2px teal focus rings incl. skip link; touch targets ≥44px;
  reduced-motion emulation zeroes transitions; contrast ratios measured
  in-page (body 14.5:1, pressed segment 8.5:1, meta 4.9:1, badge fixed
  from 4.36:1 to 5.5:1 with `--ok-ink`).
- Mock harness deleted after inspection; no test-only code left behind.

## Limitations

- Native Tauri window not rebuilt in this pass (frontend-only change;
  Rust untouched); `scripts/launch-preview.sh` rebuilds it on next run.
- No image input in the inspecting model; verification used accessibility
  snapshots + computed styles + geometry rather than pixel viewing.
