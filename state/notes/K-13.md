# K-13 — Graded reading (interlinear story mode)

## What shipped

A Reading route rendering pack-declared stories as interlinear
sentence blocks: tap a sentence → play its audio (media-first,
model-output labeled) + word-lookup panel (sentence gloss + lexicon
entries whose surface occurs in the sentence). Scaffolds (furigana /
romaji) fade per sentence via the READ-001 reader against
comprehension-reading mastery — Unicode-script based, never locale.

**Formative only**: the mode records no evidence and no scheduler
state. "Graded" = scaffolded input at the learner's level, not scoring
(ROADMAP acceptance).

## Pack data

- New schema `story.schema.json` + layout `stories/*.yaml` (single
  document) + `story` content-id kind. Stories reference ordered
  `sent` sentence ids (validated refs; K-12 sentence content reused).
- ja-demo: `ja.story.demo.first-meeting` (3 sentences incl. new
  `ja.sent.demo.konnichiwa`); valid-full: `es.story.demo.intro`.
  Both validate 0/0.

## Engine (`apps/desktop/src-tauri/src/lib.rs`)

- `story_entries` loader (dir scan, yaml parse, id validation).
- `story_list` / `story_list_at`, `story_view` / `story_view_at`:
  per-sentence `reader_display` proxy (sentence as reading item),
  lookup = lexicon surfaces contained in sentence text
  (script-agnostic substring match; aid, never evidence).
- `story_audio` → `dictation_audio_at` (media `<sentence-id>.wav`
  first, TTS fallback). Registered in invoke_handler.
- `ContentKind::Story` in domain.

## UI (`apps/desktop/src/App.tsx`)

- `reading` route + nav tab; story list → story view; sentence button
  plays audio and toggles the lookup panel; banner states nothing is
  scored or saved.
