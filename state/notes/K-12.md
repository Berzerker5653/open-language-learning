# K-12 — Cloze + dictation (typed recall, guessing resistance)

## What shipped

Two sentence-level typed activities driven entirely by pack data
(`sentences/entries.jsonl`, new `sentence` schema + `sent` content-id
kind):

- **Cloze**: one pack-declared `cloze_targets` entry is blanked
  deterministically (`fnv1a(content_id) % len`) in the sentence; the
  learner types it from context. Evidence: `production-writing`,
  support 0 — the target string never appears in the task payload, so
  no disqualifying support. Satisfies docs/03 §9 typed-recall guidance.
- **Dictation**: text fully hidden; `dictation_audio` plays
  `media/<sentence-id>.wav` first, TTS fallback (labeled model-output);
  transcript never crosses IPC. Evidence: new
  `orthographic-encoding` dimension.

## Key decision — dictation dimension

MASTERY_POLICY lists `dictation-of-target` as **disqualifying support
for production-writing**. So dictation evidence must never land there:
new `MasteryDimension::OrthographicEncoding` (perception→spelling
encoding), same separation logic as K-10's
`PhonologicalDiscrimination`. Grading is exact-match on the trimmed
string (punctuation included — honest for transcription).

## Engine

- `crates/domain`: `MasteryDimension::OrthographicEncoding`,
  `ContentKind::Sent`.
- `crates/activity/spec.rs`: `ActivityKind::Dictation` family
  (`dictation`, `write-what-you-hear`, `listen-write`); `cloze`/`gap-fill`
  join RETRIEVAL (typed recall → ProductionWriting via existing map);
  `dimension_for(Dictation, Listening) => OrthographicEncoding`.
- `crates/langpack`: `sentence` schema registered; `sentences/*.jsonl`
  layout branch; sentence ids are content; cross-field validator
  `cloze_target_not_in_text` (schema can't express substring rule).
- `apps/desktop/lib.rs`: `sentence_entries` loader; `cloze_task_build`
  / `dictation_task_build` dispatched from `practice_build` on
  `production-writing` / `orthographic-encoding` modalities;
  `PracticeTask.typed`; `practice_submit` takes `answer: Option<String>`
  (typed = exact match, choice ignored); `dictation_audio` command;
  both streams join the new-item plan; activity_id = sentence id
  (engine neutrality).

## UI

`PracticeRunner` typed branch: text input + Check (disabled until
draft non-empty); cloze heading "Fill in the blank"; dictation reuses
the audio branch ("What did you hear?" + provenance label). No reveal
affordance for typed modes.
