# K-40 + K-42 — goal map + draft-content honesty (2026-10-07)

## K-40: goal-level progress map
- Native `goal_map(profile_id)` (`apps/desktop/src-tauri/src/lib.rs`):
  reads every selected pack's `curriculum/goals.yaml` +
  `curriculum/goals/*.yaml` (K-23 sharding) and
  `assessments/definitions.jsonl`; per goal emits band, review_status,
  modalities, assessed, locked (hard prereqs vs derived mastery),
  prereq records with satisfied flags, and per-modality best derived
  state + exemplar. Sorted by band then id. Registered in
  `invoke_handler`.
- UI `GoalMap` (`apps/desktop/src/home.tsx`) renders on the Progress
  route above the per-content table (`App.tsx`): band sections,
  open/locked badges, "Grows with:" prereq copy, per-modality state
  labels, draft badge, honest empty state.
- Acceptance proven by tests:
  - `goal_map_surfaces_pack_goals_with_prereqs_and_mastery`: goals
    from installed pack (not unit counts); evidence on one required
    concept moves only that modality row.
  - `goal_map_ignores_activity_volume`: 50 unrelated events leave the
    whole map identical (ADR-0002: no counts/dates/streaks).
  - Smoke walkthrough asserts `goal-map:75` over real IPC.
