# TTS-001 notes — local Japanese TTS provider (2026-10-03)

## Acceptance mapping

1. **Candidate voice/model licenses audited separately from runtime
   code.**
   `docs/provenance/tts-candidates.md`: Kokoro-82M / kokoro-multi-lang
   export = Apache-2.0 (verified from the LICENSE shipped in the
   download); sherpa-onnx runtime = Apache-2.0; ONNX Runtime = MIT;
   **espeak-ng-data = GPLv3** flagged as a copyleft obligation distinct
   from the model weights, escalated to LIC-001 (owner) before stable
   distribution. Rejected candidates recorded with license posture
   (open-jtalk voices, Piper ja_JP espeak coupling, cloud excluded).

2. **Local Japanese TTS can generate scalable practice audio.**
   `SherpaSubprocessTts` (speech-runtime/src/tts.rs) synthesizes via
   the installed sherpa-onnx runtime; `synthesizes_all_practice_
   utterances_locally` synthesizes all 12 on-ramp utterances locally
   (non-skipped run, ~23s total, each > 0.25 s at 24 kHz). Benchmark
   protocol `benchmarks/speech/protocols/ja-JP/tts-0.1.0.yaml` +
   harness `run_tts_bench.py`; measured dev-desktop RTF p50 ≈ 1.43
   (`benchmarks/speech/results/20261003T075830Z/summary.json`) —
   honest number: slower than real-time on the dev tier, recorded
   unmeasured for lower tiers.

3. **Core curated targets can override TTS with licensed recordings.**
   `speech_audio` command resolves media-first: pack `media/<unit>.wav`
   (licensed recording with license-inventory provenance) wins;
   otherwise local synthesis, explicitly labeled `source:
   "model-output"`. Test `speech_audio_prefers_licensed_media_then_
   synthesizes` proves both branches + path/allowlist safety.

## Design

- TTS subprocess over local files; `requires_network: false`.
- Synthesized audio is never pronunciation ground truth (protocol
  out_of_scope) and is labeled model output wherever persisted.
- Catalog integration deferred: kokoro export includes a multi-file
  data dir (espeak-ng-data) the per-file catalog format can't pin
  atomically; directory-capable entries are a follow-up (recorded in
  the audit doc). Runtime currently resolves vendor paths (dev).

## Owner gates

- LIC-001: espeak-ng GPLv3 distribution obligations; final licensing.
