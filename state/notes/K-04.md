# K-04 — Script-instruction activity (orthography units as pack data)

## What shipped
- New pack content type `orthography-unit` (`schemas/v0.2/orthography-unit.schema.json`):
  `id` (kind `orth`), `status`, `script` (free-form label), `symbol`,
  `reading`, optional `mnemonic`/`teaching_order`/`similar_to`, `sources`.
  Layout: `orthography/*.jsonl` (shardable), registered in
  `crates/langpack/src/layout.rs` + `schema.rs`; ids join the pack's
  content-id registry so `prerequisite_orthography` and `similar_to`
  references are checked at install.
- New mastery dimension `orthography-recognition`
  (`MasteryDimension::OrthographyRecognition`, docs/03 §4 updated).
  Symbol↔reading mapping is tracked apart from vocabulary recall.
- Runner (`orth_task_build` in lib.rs): deterministic 4-choice task;
  direction (symbol→reading vs reading→symbol) is fixed per unit by an
  FNV hash so tasks are stable without RNG; distractors are other units'
  readings/symbols. Evidence uses the unit id as `activity_id` — no
  language literals in the engine. Scheduler row
  `<orth-id>#orthography-recognition` (per-dimension memory).
- New-item stream: orth units join `build_plan` for brand-new profiles,
  so the zero-knowledge on-ramp starts with the alphabet.
- Kana-literacy roll-up (`establish_kana_literacy`): when every
  kana-script unit the active pack teaches reaches `supported`
  recognition, profile setting `kana-literacy-established` is set —
  which the K-03 reader uses to fade kana romaji. Script detection is
  Unicode-based (`script_of`), never locale; any pack teaching any
  script gets the same roll-up for its kana-like base alphabet.
  Monotonic by design (docs/03 §4).
- ja-demo pack: `language/orthography.yaml` (hiragana script),
  `orthography/units.jsonl` (16 kana incl. confusable pairs),
  unit `010-kana-hiragana.yaml`, goal `ja.goal.demo.kana-hiragana`,
  assessment `ja.assess.demo.kana-recognize`. Mnemonics are
  AI-assisted, `review-needed`, provenance-recorded
  (`ai-drafted-kana` source) per AGENTS.md research discipline.
- UI: orth tasks render through the existing choice runner with a
  neutral heading ("Which one matches?") and no reading-reveal button
  (revealing romaji would leak the answer).

## Language-pack reuse
Everything is declarative: a Korean pack ships `orthography/jamo.jsonl`
with `script: "hangul"` symbols/readings/mnemonics and gets the same
runner, scheduling, and literacy roll-up. No ja-JP literals were added
to the engine.
