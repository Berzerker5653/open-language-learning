# K-22 — Chunking conventions for growing packs

## What shipped

Documented conventions in `docs/PACK_AUTHORING_CONTRACT.md`
("Chunking conventions (packs past A1)"):

- Lexicon sharded by topic: `lexicon/<topic>.jsonl` (kebab-case;
  never alphabetical shards — topic shards match how units cite vocab).
- One unit per lesson: `curriculum/units/NNN-<topic>.yaml`, zero-padded
  sequence = presentation order; unit ids stay semantic.
- Sentences/kanji shard past ~200 records (`sentences/food.jsonl`,
  `kanji/n5.jsonl`); the engine reads every `*.jsonl` in those dirs in
  file-name order.
- Stories: one file per text (`stories/<topic>-<band>.yaml`).
- Goals remain single-file (sharding is K-23).
- Ids are pack-global; cross-file duplicates fail (`duplicate_ids`).

No engine change: the layout contract already accepts all of it.
