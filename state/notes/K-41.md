# K-41 — stress-mark visibility (2026-10-07)

## What shipped

Readings that carry U+0301 (combining acute accent) render with the
stressed base+mark pair highlighted, in every surface that shows a
reading: practice runner (all three placements: home, placement, kanji),
and writing-practice reading hints.

- `apps/desktop/src/stress.tsx` — `StressMode`, `DisplaySettingsView`,
  `stressEnabled`, `stressRuns` (splits at U+0301, attaching the mark to
  its base vowel), `StressText` (wraps stressed runs in
  `<span class="stress" aria-label="… (stressed)">`).
- `packages/ui/src/styles.css` — `.stress` (accent ink, bold, underline).
- Native (`apps/desktop/src-tauri/src/lib.rs`):
  - `pack_has_stress_marks` scans installed pack `lexicon_texts` for U+0301.
  - `display_settings` / `set_display_settings` commands; per-profile
    setting key `stress-mode` (values auto/on/off; invalid → auto),
    same persistence pattern as `romaji-mode`.
  - `DisplaySettings { stress_mode, pack_has_stress }` view;
    `display_settings_at` is the testable core.
- UI wiring (`App.tsx`): `display` state fetched at all three load paths
  (smoke, finishOnboarding, resumeProfile); `setStressMode` handler calls
  `set_display_settings` with `{ profileId, stressMode }` (Tauri
  snake→camel arg conversion); `stress={stressEnabled(display)}` flows
  into `PracticeRunner` (3 sites) and `WritingPractice`.
- Toggle UI: Languages page "Display settings" section
  (`language.tsx`) — auto/on/off `aria-pressed` buttons.

## Honesty invariants

- Display-only: grading, evidence, and scheduling never consult the
  setting (enforced by construction — no grading path reads it; native
  test asserts the setting round-trips without touching mastery).
- Data-driven: no language literals. ja-JP (no U+0301 anywhere) renders
  unchanged; ru-RU lexicon readings get the highlight. `auto` follows
  `pack_has_stress`; `on`/`off` override explicitly.

## Tests

- Native: `stress_display_settings_are_data_driven_and_persisted` —
  ja-JP has no stress data, ru-RU (installed directly via
  `lts_langpack::archive::build/install`; not in `bundled_packs()`) does;
  mode persists across `display_settings_at` calls; `switch_pack` flips
  `pack_has_stress`; invalid mode → auto.
- UI: `src/stress.test.tsx` (4 tests) — split attaches mark to base
  vowel (`о\u0301` alone highlighted, not the whole prefix), null for
  unmarked text, exactly one highlight span rendered, auto/on/off
  override matrix incl. null settings.
- `language.test.tsx` base render carries the new props.

## Bug found while testing

`stressRuns` initially accumulated everything up to the mark into the
stressed run (`сего́` instead of `о́`). Fixed: on seeing U+0301, peel the
base char off the pending plain run, flush the remainder unstressed, and
push only `base + mark` as the stressed unit.
