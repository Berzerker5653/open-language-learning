# ACT-001 — activity runtime and support ladder

Date: 2026-10-03. Evidence: `state/evidence/ACT-001/{cargo-test,ci}-2026-10-03.txt`.

## What was built

New crate `crates/activity` (`lts-activity`):

- `spec.rs` — `ActivityRuntime::from_pack(&Pack)` loads units, scenarios,
  lexicon cards, and concept notes from pack instances into typed
  structures; `render(activity_id)` produces a serializable
  `RenderedActivity` spec (kind, modality, mastery dimension, declared
  support level, resolved prompt content/concepts, scenario nodes +
  pack-declared support ladder, default support options). Pack activity
  `type` strings map to the four families via a documented table
  (`classify_type`); unknown types fail at load, so no pack can silently
  render an unhandled activity. `dimension_for` maps
  (kind, pack modality) → mastery dimension conservatively
  (retrieval+reading → recall-meaning; explanation → grammar-controlled).
- `support.rs` — `SupportAction` (context-cue, replay, slow-input,
  meaning-hint, text-cue, word-bank, choice-support,
  partial-translation, response-template, full-translation,
  modeled-response) with docs/03 §5 default levels 1–5;
  `SupportLedger` records concrete actions taken during an attempt —
  support revealed earlier stays part of the attempt's evidence.
- `attempt.rs` — `Attempt::begin/render → use_support → submit`
  finalizes through the LEARN-001 `AttemptDraft` into an immutable
  `EvidenceEvent` carrying `support_actions` (labels) + ordinal
  `support_level` (max action); `independent_success` is true only for
  Correct with minimal help (level ≤ 1). `skip` records a non-linguistic
  Skipped event.
- Fixture: `valid-full` unit extended with encounter/retrieval/
  explanation activities so all four kinds render from pack data.

## Acceptance mapping

1. **Four activity types render from pack data** —
   `runtime.rs::all_four_activity_kinds_render_from_pack_data`: each of
   encounter/comprehension/retrieval/explanation renders with kind,
   dimension, prompt content resolved from lexicon instances ("hola"
   form), concept notes, and scenario nodes + ladder from the scenario
   YAML. A throwaway example additionally dumped the full JSON render
   specs (UI-consumable; UX-002/M4-E2E will bind the screens).
2. **Hints/replays/translations emit support evidence** —
   `hints_replays_translations_emit_support_evidence`: Replay +
   FullTranslation during an attempt → evidence
   `support_actions == ["replay","full-translation"]`,
   `support_level == 5`, attempt group preserved.
3. **Correct with strong help ≠ independent success** —
   `correct_with_strong_help_is_not_independent_success`: same Correct
   answer, no support → `independent_success: true`; with word-bank +
   response-template → `false` (level 4). End-to-end through the
   versioned mastery policy: helped event alone derives a state below
   Independent with strictly lower confidence than two independent
   correct attempts across prompt families (Independent).
