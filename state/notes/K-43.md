# K-43 — per-pack content claims panel (2026-10-07)

## What shipped

The Languages page now shows, for each installed pack, what the pack
itself claims: content counts, its own review-posture distribution, and
its stated sources. Nothing here is verification — the panel says so,
and `trust_state` passes through from the install gate untouched.

- Native (`apps/desktop/src-tauri/src/lib.rs`):
  - `pack_claims()` command → `pack_claims_at(data)` reads the installed
    pack store (`store.installations()` + `archive::current_version`)
    and tallies from the pack's own files:
    - JSONL kinds via `jsonl_claims` (assessments, sentences, grammar,
      kanji, phonology contrasts; sharded `lexicon/*.jsonl` and
      `orthography/*.jsonl` summed);
    - YAML goals via `yaml_goal_claims` (reuses `pack_goal_files`,
      K-23 sharding);
    - YAML units via `yaml_unit_claims` (multi-doc `---` files under
      `curriculum/units/`);
    - YAML stories via `stories/*.yaml` mappings.
  - Posture tally reads `status` (content records) or `review_status`
    (goals/assessments); unlabeled records count as `unlabeled`.
  - `provenance` surfaces `sources.jsonl` entries (id/title/url/license
    spdx/access mode) as claims.
  - `PackClaims { pack_id, version, trust_state, counts, postures,
    provenance }` — `trust_state` is the install gate's value, passed
    through; claims never promote it.
- UI (`language.tsx`): "What this pack claims (version)" block per
  installed pack — counts list, "Review posture (the pack's own
  labels)" rows (`kind: N posture`), "Stated sources" list. Copy states
  explicitly: "these are the pack's claims, not our verification.
  Install posture stays '<trust_state>' regardless of these counts."
- `App.tsx`: `claims` state fetched via `pack_claims` in
  `refreshLanguages` (runs on Languages-page entry and after
  install/import/switch).

## Honesty invariants

- Counts are derived from installed pack data only — no hardcoded
  numbers, no language literals.
- `trust_state` is never upgraded by claims (test asserts it stays
  "community" after install).
- Posture distribution exposes draft-heavy reality (ja-JP: thousands of
  `draft` lexicon records, zero `verified`).

## Tests

- Native `pack_claims_report_installed_pack_data_without_upgrading_trust`:
  counts match the real ja-JP pack (goals == goal_map length), posture
  tallies sum to each kind's count, draft posture present, no verified
  lexicon rows, provenance non-empty with titles, trust_state ==

- UI `language.test.tsx` "renders per-pack content claims without
