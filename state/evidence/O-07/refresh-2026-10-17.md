## Write refusal (measured exit codes)

| invocation | exit | output |
| --- | --- | --- |
| `--check` against the pinned release | 0 | `RESULT: REPRODUCED …`, nothing written |
| `--write` against `3.6.2+20261012204142` | 2 | `ABORT: --write against an unpinned release needs --allow-unpinned` |
| `--check --write` together | 2 | `ABORT: --check and --write are mutually exclusive` |

So "writes nothing until a human asks" is enforced by exit code, not by convention:
a newer release cannot be written without an explicit `--allow-unpinned` flag that
names the risk, and the pinned-release write path requires `--write` alone.
