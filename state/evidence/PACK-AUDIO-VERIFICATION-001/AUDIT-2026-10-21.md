## Gate v2 correction

v1 compared raw strings and mis-graded artifact classes (audited before any
re-bake, to avoid feeding an inflated list to the generator):

* Japanese kanji/digit transcripts vs kana pack text: multi-word transcripts
  and kakasi homograph readings still mis-graded after the kana fold.
* whisper stage directions (`*вздыхает*`, `(笑)`) and laughter/sustained
  vowel runs (`Ха-ха-ха!`, `Уууу…`) counted as content mismatch. Under v2
  they are explicit `reasons` — still defects (the audio really contains
  those hallucinated vocalizations), but they no longer poison the ratio.
* Filler ellipses (`Кот...`) collapsed to whitespace runs before ratio.

`scripts/qa-asr-rescore.py` re-graded the recorded transcripts (no whisper
re-run); the same logic now lives inside `scripts/qa-asr.py` so the repair
loop converges on it.

Residual false-positive classes (known, accepted): kakasi homograph kanji
readings (止める -> yameru vs expected とめる) and whisper mis-hearings of
very isolated short words. The bias is deliberate: churn (re-bake a good
clip) is preferred over a false PASS; every re-bake re-enters the same
gates.

## Defect classes observed (samples)

* TTS hallucinated vocalizations: `(笑)`, `*вздыхает*`, `Ха-ха-ха!`,
  `Уууу…` sustained vowels, `ふぅ…く…`.
* Mispronunciation: чек -> "Чик", пло́хо -> "ПЛАХА", цена́ -> "Сэна".
* Wrong/garbled content: ссылаться -> "Слаца!", достоверный -> "До свидания.",
  はんのう -> "I know", software-update sentences -> babble.
* Structure (segments): internal silence gaps > 0.8 s, pre-speech bursts.

## Repair campaign

`scripts/bake-repair-loop.sh` (ALL_GATES=1, up to 8 rounds), ru-RU first
then ja-JP, `VENV=.venv/bin/python` + whisper ggml-small. Synthesis is CPU
(`qwen3-tts-worker.py device_map=cpu`), so the campaign coexists with the
GPU inference server. Per-round logs land at repo root
(`repair-r*.log`, `qa-r*.{jsonl,log}`, `qs-r*.jsonl`) and are summarized
here at campaign end, not committed.
