# Open Language Learning Platform 0.5.0-alpha.1

The first alpha learners can actually use day one through week three: onboarding
builds a real learner plan, practice is five independent modes, and phone access
over the home/Tailscale network is hardened and observable.

This is an alpha: local-first desktop app for Linux (AppImage + .deb). Windows and
macOS artifacts are compiled-check only — nobody has run them on real hardware.

## What's new since 0.4.0-alpha.1

### Five practice modes, independent scores
- **Flashcards** — self-rated, honest confidence tracking.
- **Multiple-choice** — word-form aware, two-point distractors.
- **Typing** — full inflected forms accepted, no typing diacritics required.
- **Dictation** — hear it, type it; whisper-based scoring with honest
  abstention when audio is unclear.
- **Shadowing** — record yourself speaking; playback + waveform, no fake scoring.
- New learners start on multiple-choice; all modes unlock by default, no grind-gating.

### The first three weeks have real content
- 248-lesson Russian path nodes with per-node word pools (2,555 pool senses)
  and 1,721 word-tap audio clips — click any word in the reader to hear that
  exact inflected form.
- 32 graded stories (A1–B1) written from level-restricted vocabularies, with
  tap-to-translate word cards; 20 comprehension quizzes.
- Listening player: continuous playback, loop-A/B, real speed control.
- A daily plan that survives a missed day and always has a concrete next action.

### Phone + network access
- Pair devices with a PIN; per-profile access grants (viewer / practice / full)
  so a phone only sees the profile it belongs to.
- HTTPS via tailscale-serve verified end-to-end; LAN mode off by default.
- Native-feeling mobile UI: bottom tabs, safe areas, cards sized for thumbs.

### Polish pass across the whole app
- Warm "calm but competitive" visual redesign targets: activity rings, path
  map, celebration moments, motion — applied surface by surface.
- First-run onboarding with instant first win and a real plan on the first screen.
- Profile switching without restart; deleting a profile can't destroy others.

### Under the hood you'll feel
- Offline-first: everything works with zero network; catalog updates in background.
- Update failures are now classified (no network vs bad signature vs blocked
  download) instead of one generic error.
- Search, backups, and progress screens rebuilt around what learners ask for.

## Known alpha limits (we won't pretend)
- Content quality is **draft**: Russian/Japanese packs were generated by an AI
  author pipeline with mechanical verification (dictionary checks, stress
  checks, ASR gates) — not yet human-reviewed. Corrections welcome via
  issues; learner 👍/👎 ratings drive promotion.
- Japanese narrator voice consistency was never listened to by a human;
  ASR verification confirmed audio correctness mechanically.
- The in-app updater is not wired yet — download new versions from Releases.
- Windows/macOS builds are unvalidated on hardware.
- Windows smart-screen/SmartGATE warnings are expected for unsigned alphas.

## Install (Linux)
- `open-language-learning-platform_0.5.0-alpha.1_amd64.deb` — Debian/Ubuntu
- `open-language-learning-platform_0.5.0-alpha.1_amd64.AppImage` — everything else
  (make executable, run it; `--appimage-extract-and-run` if FUSE is unavailable)
- `…-aligner.deb` / `…-aligner.AppImage` — same app plus the bundled offline
  whisper.cpp speech aligner (larger download; the base build asks for an
  external aligner instead)

Requires AVX2-capable x86-64 CPU (aligner variants).
